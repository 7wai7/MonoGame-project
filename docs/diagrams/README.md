# Візуальна документація рушія

Ці діаграми описують не абстрактний ECS або абстрактну фізику, а поточну
реалізацію цього проєкту:

1. [Загальна архітектура](01-engine-overview.md) — які шари існують і хто ким
   володіє.
2. [Життєвий цикл та один кадр](02-game-loop.md) — як MonoGame запускає рушій,
   оновлення й рендеринг.
3. [Життєвий цикл ECS-сутності](03-ecs-lifecycle.md) — створення, компоненти,
   запити, видалення та generation.
4. [Sparse set та EntityQuery](04-ecs-storage-and-query.md) — як компоненти
   лежать у пам'яті та як знаходиться перетин компонентів.
5. [Фіксований крок фізики](05-physics-fixed-step.md) — повний порядок роботи
   PhysicsSystem.
6. [Життєвий цикл фізичного тіла](06-physics-body-lifecycle.md) — створення,
   оновлення collider та видалення Jitter body.
7. [Рендеринг та інтерполяція](07-render-interpolation.md) — як фізичні пози
   перетворюються на плавне зображення.

## Кольори

- синій — MonoGame та основний цикл рушія;
- фіолетовий — сцена й планувальник систем;
- жовтий — ECS-дані;
- червоний — Jitter і фізична симуляція;
- зелений — 3D-рендеринг.

Mermaid-діаграми відображаються безпосередньо на GitHub. У VS Code для
попереднього перегляду можна відкрити Markdown Preview; якщо встановлене
розширення не підтримує Mermaid, текстове покрокове пояснення під кожною
діаграмою залишається повним.
